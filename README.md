🚢 Titanic Survival Analysis Dashboard

 📌 Project Overview
This project analyzes the famous **Titanic dataset** to uncover key factors that influenced passenger survival.  
Data was cleaned using **Microsoft Excel** and visualized in **Power BI** to create an interactive dashboard.

The objective is to explore how variables such as **passenger class, gender, age, and fare** impacted survival outcomes.



🛠️ Tools Used
- Microsoft Excel – Data cleaning and preparation  
- Power BI – Data visualization and dashboard creation  



 📂 Project Structure
data/ → Titanic dataset (Excel)  
powerbi/ → Power BI dashboard (.pbix)  
images/ → Dashboard screenshot  
README.md → Project documentation  

---

🔍 Data Analysis Process
1. Cleaned and prepared the dataset in Excel  
2. Handled missing values (Age, Embarked, etc.)  
3. Created calculated measures in Power BI  
4. Built interactive dashboard with slicers  
5. Analyzed survival patterns and trends  

---

 📊 Key Performance Indicators (KPIs)
The dashboard highlights key summary metrics:

- **Survival Rate:** 38.4%  
- **Average Age:** 30 years  
- **Total Fare:** $29K  
- **Total Passengers:** 891  
- **Total SibSp (Siblings/Spouses):** 466  

---

 🎛️ Interactive Filters (Slicers)
Users can dynamically filter the dashboard using:

- **Sex**
- **Passenger Class (Pclass)**
- **Port of Embarkation (Embarked)**

These filters allow deeper exploration of survival patterns across different groups.



 📈 Dashboard Visualizations & Insights

 1. Survival Rate by Passenger Class
- **1st Class:** 63% (Highest survival rate)  
- **2nd Class:** 47%  
- **3rd Class:** 24% (Lowest survival rate)  

📌 **Insight:** Higher-class passengers had significantly better survival chances, indicating social and economic factors played a major role.

---

 2. Total Fare by Passenger Class
- **1st Class:** ~$18K–$19K (Highest contribution)  
- **3rd Class:** ~$7K  
- **2nd Class:** ~$4K (Lowest contribution)  

📌 **Insight:** Despite fewer passengers, 1st class generated the highest revenue due to expensive ticket prices.



 3. Gender Distribution
- **Male:** 577 passengers (64.76%)  
- **Female:** 314 passengers (35.24%)  

📌 **Insight:** The dataset is male-dominated, which is important when analyzing survival rates by gender.
